## 课后题

### 名词解释

**1. 商业银行**

商业银行是市场经济的产物，它是为适应市场经济发展和社会化大生产需要而形成的一种金融组织。商业银行经过几百年的发展演变，现在已经成为世界各国经济活动中最主要的资金集散机构，其对经济活动的影响力居于各国各类银行与非银行金融机构之首。

商业银行是以追求最大利润为目标，能向客户提供多种金融服务的特殊的金融企业。盈利是商业银行产生和经营的基本前提，也是商业银行发展的内在动力。

### 问答题

**1. 简要说明商业银行的性质和功能**

**性质**：
1. 商业银行是企业
2. 商业银行是金融企业
3. 商业银行是特殊的金融企业

**职能**：
1. 信用中介
2. 支付中介
3. 信用创造：k = ΔD/ΔP = 1/rd
4. 金融服务
5. 代理监督和经济调节

**2. 比较商业银行外部组织形式的利弊，简述商业银行的内部组织结构**

**内部组织结构**：

**决策机构**：
- 股东大会是商业银行的最高权力机关
- 董事会是由股东大会选举产生的决策机构
- 董事会下设的各种委员会或附属机构

**执行机构**：
- 总经理(行长)是商业银行的行政主管，是银行内部的首脑
- 副总经理(副行长)及各业务、职能部门

**监督机构**(>3人)：
- 监事会
- 商业银行的稽核部门是董事会或管理层领导下的一个部门，其职能是维护银行资产的完整和资金的有效运营，对银行的管理与经营服务质量进行独立的评估，是商业银行实施内部控制的重要机构

**外部组织形式**：
1. 单元制银行组织结构：只通过一个营业机构提供全部服务
2. 分支行制组织结构
3. 银行控股公司组织结构
4. 电子银行和电子商务

**3. 比较商业银行分业经营和混业经营模式的利弊**

分业经营可以降低经营风险，避免货币市场的资金直接流入高风险的资本市场，维护一国的金融稳定；客观上起到遏制垄断、维护竞争的作用；专业化分工，集中在某一特定领域的产品和服务。
