## 第一章 绪论

### 1-1. 现代地籍的含义是什么？

现代地籍是指由国家监管的、以土地权属为核心、以地块为基础的土地及其附着物的权属、位置、数量、质量和利用现状等土地基本信息的集合，用数据、表册和图册等形式表示。

### 1-2. 简述地籍发展的三个阶段

1. **税收地籍阶段**：主要为税收服务
2. **产权地籍阶段**：主要为保护土地权属服务
3. **多用途地籍阶段**：为土地管理、规划、税收、产权保护等多方面服务

### 1-3. 现代地籍有哪些功能？

1. **税收功能**：为土地税收提供依据
2. **产权保护功能**：保护土地所有权和使用权
3. **土地管理功能**：为土地管理提供基础信息
4. **规划功能**：为城乡规划提供基础数据
5. **法律功能**：为土地纠纷提供法律依据

### 1-4. 地籍测量学的主要内容是什么？

1. 地籍控制测量
2. 界址测量
3. 地籍图测绘
4. 土地面积量算
5. 变更地籍测量

### 1-5. 地籍测量的特点有哪些？

1. **法律性**：地籍测量成果具有法律效力
2. **精确性**：要求较高的测量精度
3. **现势性**：需要保持地籍资料的现势性
4. **综合性**：涉及土地及其附着物的各项信息

## 第二章 土地权属调查

### 2-1. 什么是土地权属？

土地权属是指土地所有权、使用权和他项权利的归属。

### 2-2. 我国土地所有权的类型有哪些？

1. **国家所有**：城市市区的土地属于国家所有
2. **集体所有**：农村和城市郊区的土地，除法律规定属于国家所有的以外，属于集体所有

### 2-3. 土地权属调查的内容包括哪些？

1. 土地所有权人
2. 土地使用权人
3. 土地权属性质
4. 土地用途
5. 土地使用期限
6. 土地界址

### 2-4. 什么是界址点？界址线？

- **界址点**：土地权属界线的拐点
- **界址线**：土地权属界线

### 2-5. 土地权属调查的程序是什么？

1. 准备工作
2. 实地调查
3. 界址调查
4. 填写调查表
5. 绘制宗地草图
6. 权属审核

## 第三章 土地利用现状调查

### 3-1. 土地利用现状调查的目的是什么？

1. 查清各类土地的数量和分布
2. 为土地规划、管理提供依据
3. 为土地评价提供基础资料

### 3-2. 我国土地利用现状分类体系是什么？

根据《土地利用现状分类》，土地分为12个一级类，包括：
- 耕地
- 园地
- 林地
- 草地
- 商服用地
- 工矿仓储用地
- 住宅用地
- 公共管理与公共服务用地
- 特殊用地
- 交通运输用地
- 水域及水利设施用地
- 其他土地

### 3-3. 土地利用现状调查的方法有哪些？

1. **遥感调查法**：利用遥感技术进行调查
2. **实地调查法**：通过实地踏勘进行调查
3. **抽样调查法**：通过抽样推断总体
4. **综合调查法**：综合运用多种方法

## 第四章 土地等级调查概述

### 4-1. 什么是土地等级？

土地等级是根据土地的自然属性和经济属性，按照一定标准划分的土地质量等级。

### 4-2. 土地等级调查的意义是什么？

1. 为土地税收提供依据
2. 为土地估价提供基础
3. 为土地规划提供参考
4. 为土地交易提供指导

### 4-3. 土地等级划分的原则有哪些？

1. **综合分析原则**：综合考虑自然和经济因素
2. **主导因素原则**：以主导因素为依据
3. **地域差异原则**：考虑地域差异
4. **科学实用原则**：科学性与实用性相结合

## 第五章 房屋调查

### 5-1. 房屋调查的内容包括哪些？

1. 房屋权属
2. 房屋位置
3. 房屋结构
4. 房屋层数
5. 房屋建筑面积
6. 房屋用途
7. 房屋建成年份

### 5-2. 房屋结构类型有哪些？

1. **钢结构**
2. **钢-钢筋混凝土结构**
3. **钢筋混凝土结构**
4. **混合结构**
5. **砖木结构**
6. **其他结构**

### 5-3. 房屋建筑面积如何计算？

房屋建筑面积是指房屋外墙（柱）勒脚以上各层的外围水平投影面积，包括阳台、挑廊、地下室、室外楼梯等，且具备有上盖，结构牢固，层高2.20m以上（含2.20m）的永久性建筑。

### 5-4. 房屋调查的注意事项有哪些？

1. 实地核实房屋情况
2. 准确测量房屋尺寸
3. 了解房屋权属状况
4. 记录房屋使用状况

## 第六章 地籍控制测量

### 6-1. 什么是地籍控制测量？

地籍控制测量是在地籍测量区域内，建立地籍控制网，为界址测量和地籍图测绘提供基础控制。

### 6-2. 地籍控制测量的精度要求是什么？

地籍控制测量的精度要求：
- 四等网中最弱相邻点的相对点位中误差不得超过5cm
- 一级网中最弱相邻点的相对点位中误差不得超过5cm
- 二级网中最弱相邻点的相对点位中误差不得超过5cm

### 6-3. 地籍控制点的密度要求是什么？

地籍控制点的密度应根据测区范围、测图比例尺和测量方法确定，一般要求：
- 城市建成区：每平方公里不少于10点
- 城市规划区：每平方公里不少于4点
- 其他地区：根据实际需要确定

### 6-4. 地籍控制测量的方法有哪些？

1. **三角测量**
2. **导线测量**
3. **GPS测量**
4. **边角测量**

## 第七章 界址测量

### 7-1. 什么是界址测量？

界址测量是测定界址点坐标和界址线位置的工作，是地籍测量的核心内容。

### 7-2. 界址点的精度要求是什么？

界址点的精度等级分为两级：
- **一级**：界址点相对于邻近控制点的点位中误差不超过±5cm
- **二级**：界址点相对于邻近控制点的点位中误差不超过±7.5cm

### 7-3. 界址测量的方法有哪些？

1. **解析法**：使用全站仪、GPS等仪器直接测定界址点坐标
2. **图解法**：在地籍图上图解界址点坐标
3. **部分解析法**：解析法与图解法相结合

### 7-4. 界址测量的程序是什么？

1. 准备工作
2. 界址点标定
3. 界址点测量
4. 界址点坐标计算
5. 界址点成果整理

## 第八章 地籍图的测绘

### 8-1. 什么是地籍图？

地籍图是表示土地权属界线、界址点、地块号、地类号、宗地面积等要素的专题地图。

### 8-2. 地籍图的比例尺有哪些？

- 城市地区：1:500、1:1000
- 农村地区：1:2000、1:5000、1:10000

### 8-3. 地籍图的基本内容有哪些？

1. **地籍要素**：
   - 行政界线
   - 权属界线
   - 界址点
   - 宗地号
   - 地类号
   - 宗地面积

2. **地形要素**：
   - 建筑物
   - 道路
   - 水系
   - 植被

3. **数学要素**：
   - 图廓线
   - 坐标网
   - 比例尺
   - 图例

### 8-4. 地籍图的测绘方法有哪些？

1. **平板仪测图**
2. **全站仪测图**
3. **航测成图**
4. **数字测图**

### 8-5. 地籍图的分幅与编号原则是什么？

1. **分幅原则**：按国际标准分幅或正方形分幅
2. **编号原则**：采用图幅西南角坐标公里数编号或行列式编号

## 第九章 土地面积量算

### 9-1. 土地面积量算的基本原则是什么？

1. **图幅为基本控制**：以图幅理论面积为基本控制
2. **分层量算**：按行政级别和权属级别分层量算
3. **逐级平差**：从高到低逐级平差
4. **严格校核**：对量算结果进行严格校核

### 9-2. 土地面积量算的方法有哪些？

1. **解析法**：
   - 坐标法
   - 几何图形法

2. **图解法**：
   - 方格法
   - 求积仪法
   - 数字化法

### 9-3. 坐标法计算面积的公式是什么？

```
P = 1/2 |Σ(Xi·Yi+1 - Xi+1·Yi)|
```

其中：Xi、Yi为界址点坐标

### 9-4. 土地面积量算的精度要求是什么？

1. **解析法**：相对误差不超过1/500
2. **图解法**：两次量算较差不超过图上0.3mm²

### 9-5. 什么是面积平差？

面积平差是将量算误差按面积大小或界线长度比例分配到各宗地的过程，使量算面积与理论面积一致。

## 第十章 日常地籍调查

### 10-1. 什么是日常地籍调查？

日常地籍调查是指在初始地籍建立后，因土地权属、界址、用途等发生变化而进行的动态调查和更新。

### 10-2. 日常地籍调查的内容有哪些？

1. **土地权属变更调查**
2. **界址变更调查**
3. **用途变更调查**
4. **他项权利变更调查**
5. **注销登记调查**

### 10-3. 日常地籍调查的程序是什么？

1. 变更申请
2. 变更审核
3. 实地调查
4. 测量变更
5. 资料更新
6. 归档备案

### 10-4. 变更地籍测量的方法有哪些？

1. **重新测量法**：对变更宗地重新进行测量
2. **修补测量法**：仅对变更部分进行测量
3. **坐标变换法**：利用坐标变换进行变更

### 10-5. 日常地籍调查的要求有哪些？

1. **及时性**：变更发生后及时进行调查
2. **准确性**：保证调查成果的准确性
3. **连续性**：保持地籍资料的连续性
4. **完整性**：保持地籍资料的完整性

## 附录：重要概念总结

### 地籍测量基本概念

- **地籍**：记载土地位置、界址、数量、质量、权属和用途等基本状况的簿册
- **宗地**：被权属界线封闭的地块
- **界址点**：土地权属界线的拐点
- **界址线**：土地权属界线
- **地籍图**：表示地籍要素的专题地图

### 测量精度要求

| 项目 | 精度要求 |
|------|----------|
| 四等控制网相对点位中误差 | ≤5cm |
| 一级控制网相对点位中误差 | ≤5cm |
| 二级控制网相对点位中误差 | ≤5cm |
| 一级界址点点位中误差 | ≤±5cm |
| 二级界址点点位中误差 | ≤±7.5cm |
| 解析法面积量算相对误差 | ≤1/500 |
| 图解法面积量算较差 | ≤0.3mm² |

### 地籍比例尺适用范围

| 比例尺 | 适用范围 |
|--------|----------|
| 1:500 | 城市建成区 |
| 1:1000 | 城市规划区 |
| 1:2000 | 城市郊区、县城 |
| 1:5000 | 农村居民点 |
| 1:10000 | 农村地区 |
