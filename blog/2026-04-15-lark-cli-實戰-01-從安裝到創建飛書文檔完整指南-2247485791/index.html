Lark-cli docs +fetch 返回文樓的 Markdown 内容(Lark-flavored 格式),包含文樓标题、长度、正文。可用 来检查文檀當前内容後再决定如何更新。

五、踩坑記錄(真實遇到的問题)​

5.1長文槛必须分段寫入​

刑晋API对单次寫入有限制實测中發现一篇9章衍的文楼無法一次性寫入,需要: 别建主经 lark-cli docscreate --title“棵题--markdown“第—部分 #逐段通加 lark-cli docs +update --doc

  • -narkdown“第二部分”

"xxx" puadde apou-

5.2搜索文檔需要额外權限​

實涮docs +search罐:

  • ok": falsc,

  • error":{

"type": "missing scope", 'nessage*: nissing required scopc(s]: scarch=docs:read

search:docs:read scope: 需要额外授權 lark-cli auth login --scope search:docs:read

5.3圆片插入是巽步的​

插入圖片不會立即生效,返回的是task_id: "status":"running" "task_id":"418dcd05-052f-4fa8-bdda-ec231c0e3b49", "estimated_time":"5-15s"

實測約8秒後圖片才出現在文檔中。

5.4bash中---會被解析為flag​

在shell中通過$(catfile)傅含 分割線的Markdown時,bash會把 當作命令行flag,導致報錯。 解决方案:直接在参数中寫内容,避免用$(cat) 展開。
